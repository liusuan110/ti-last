# 从李萨如图形到闭环控制

装置面对的事情看起来很直观：让示波器显示一条对角线、一个圆或一个“∞”。真正要控制的却是两路正弦信号之间的关系。本篇沿着这个关系展开，先看电输入模式，再看断开电连接后怎样用图像完成同一件事。

## 图形背后的三个量

在 X-Y 模式下，可以把两路信号写成：

```text
x(t) = A cos(2πft)
y(t) = B cos(2πrft + φ)
```

这里的 `r` 是频率比，`φ` 是相位差，`B/A` 是幅度比。频率相同、相位相同且等幅时，轨迹是一条对角线；相位差变成 90°，轨迹展开为圆；把 Y 轴频率变为两倍，再调到合适相位，就得到对称的“∞”。

因此，设计的主线是：**先找到输入频率，再设定频率比，随后调整相位和幅度。** 当示波器灵敏度固定为 0.5 V/div 时，Y 轴 2/4/6/8 div 分别对应 1/2/3/4 Vpp。

[AD9959](../User/AD9959.h) 为这三个量提供了数字接口：频率控制字 FTW、14 位相位字 POW 和 10 位幅度字 ASF。当前 DDS 系统时钟为 25 MHz，输出频率按下面的关系设置：

```text
FTW = round(f_out × 2^32 / 25,000,000)
```

从这里开始，图形问题就转成了控制参数的问题。

## 电输入模式：先测频，再锁相

常规模式中，输入经过调理与整形，一路送到 PA16 用于测频，另一路进入鉴频鉴相器 PFD。AD9959 的 CH1 经整形提供参考信号，PFD 的低通输出送到 PA27，成为主控能够读取的相位反馈。

测频给出 DDS 的起始频率；反馈环继续修正参数，使两路信号保持稳定关系。这样，频率选择和相位保持各有明确的信息来源。相关调度和状态保存在 [User/App.c](../User/App.c)，采样与数据搬运由 [AdcCapture](../User/AdcCapture.c)、DMA 和中断配合完成。

CH0 是最终送往示波器 Y 轴的输出，经过滤波、放大和继电器选择后接入屏幕。PA13 控制继电器：低电平走输入直通，高电平走 DDS 输出。直通用于直接观察输入关系，DDS 路径用于生成正交与二倍频信号。

幅度调节还要处理放大链路的频率响应。当前固件用 `gAmpAnchorHz` 和 `gAmpAnchorAsf` 保存六个频率锚点及四档幅度，并在锚点之间插值；圆形输出也保留了相位起始值表。它们把实物标定结果带回程序，编码器则提供现场微调。

操作时先按 UP 完成电测频与锁定，再用 MID 选择圆、RIGHT 选择“∞”；DOWN 切换幅度，编码器调相位，LEFT 或编码器按下回到直通。

## 断开电连接后，频率从哪里来

要求 5 中，信号源只连接示波器 X 轴。主控失去了电输入，但摄像头仍能看到屏幕。单张李萨如图形主要描述两路信号的相对关系，要从中直接恢复未知频率并不方便。

测频阶段因此先换一种 Y 轴信号：由 PA15 输出一段已知时长的线性斜坡。随着斜坡上升，屏幕的纵向位置对应了窗口内的时间；沿纵向读取 X 轴正弦轨迹，就能估计这段时间里经过了多少个周期。

这一步把“从图形猜频率”变成了“在已知时间窗口里读波形”。[ramp_frequency.py](../DK2500_vision/ramp_frequency.py) 提取轨迹并估计频率，[fast_phase_lock.py](../DK2500_vision/fast_phase_lock.py) 再搜索相邻的 100 Hz 候选并做精调。窗口斜坡、轨迹分析和 DDS 搜索由此连成一条测频链路。

早期尝试用 TSL1401 只扫描屏幕的一条竖线，从亮点间距和数量恢复信息。后续改用 UVC 摄像头，取得整幅轨迹，频率估计和形状判断都能利用更多几何特征。两条路线的实验过程见[工程演进](ARCHIVE.md)。

## 频率找到了，为什么图形还会转

输入与 DDS 之间只要有很小的频差，相位就会随时间积累，屏幕上的图形也会持续变化。把频率显示成同一个整数，并不意味着二者已经同步。

工程为 DDS 保存了 21 个频偏补偿锚点，并继续观察轨迹的变化来细调 FTW。[requirement5_target.py](../DK2500_vision/requirement5_target.py) 把盲锁得到的精确 FTW 和初始相位直接交给形状控制，而不是在下一阶段只根据取整后的频率重新生成参数。这样，前一阶段找到的锁定结果可以连续地用下去。

形状控制接手后继续读取图像。若相位需要持续朝同一方向调整，[shape_control.py](../DK2500_vision/shape_control.py) 会结合一段时间内的相位变化，对 FTW 做小步修正，使相位控制与频偏补偿配合工作。

## 三种图形怎样各自收敛

不同图形需要不同的反馈量。直线看轨迹是否紧凑、线宽和间隙是否缩小；圆看椭圆轴比与角度覆盖；“∞”看中心穿越位置和两侧叶瓣是否对称。控制程序据此调整相位，再用后续图像判断调整方向是否有效。

一次完整运行从物理按键开始。PA16 无电输入时，LEFT / MID / RIGHT 分别产生 `line / circle / infinity` 请求。[按键服务](../DK2500_vision/requirement5_button_service.py) 收到事件后，把串口交给目标流程；目标流程依次完成盲测频、FTW 交接和形状保持。

最后版本采用 `--fast-handoff`，让形状控制更早接手，减少各阶段重复等待。随后视觉反馈持续运行，图形第一次收敛后仍继续修正漂移。MCU 复位时，流程回到按键监听，等待下一次操作。
